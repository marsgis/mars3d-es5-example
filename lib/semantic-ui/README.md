# Semantic UI
语义化前端 UI 组件框架

## 简要介绍
语义化类名的 CSS/JS UI 框架，提供按钮、表单、弹窗、菜单等丰富组件；`themes/` 子目录含默认主题与图标字体。

## 相关地址
- 官网地址：https://semantic-ui.com
- github地址：https://github.com/Semantic-Org/Semantic-UI

## 本地版本信息
2.4.1

## 本地文件说明
含 `themes/` 主题子目录。
目录内文件：`semantic.min.css`、`semantic.min.js`、`LICENSE`
